# North Star

Astrid has one boring, reliable path from an explicitly focused project/timeline to
an opened render. Runtime owns durable state and immutable media; the launcher owns
the serving process; settlement publishes outputs atomically; and user-facing code
opens only a verified, correctly named materialization.

Health remains cheap. Deep audits are offline. Recovery returns a realm to normal
launcher ownership and then disappears from the user model. No raw CAS opening,
direct-database fallback, second registry, legacy shim, or silent project fallback.
