# North Star

Finish with one compatible, tested composition across the repositories actually
selected by unified-execution, one reproducible supported CPU/local journey, and
an exact manifest proving the tested trees match the intended remote `main`
revisions after normal merges.

Preserve each project's ownership, acceptance criteria, review authority and
recoverable source inputs. Keep Runtime as the sole durable task/lease/settlement
authority; keep generated clients tied to the versioned producer contract; keep
managed bytes and disposable derivative lifecycle behavior truthful; and retain
UE's honest physical/GPU evidence requirements.

The integration manager is a thin coordinator of composition and evidence. It
does not become a sixth implementation, aggregate the workspace into a fake
source tree, duplicate a GPU fire, add an oracle/review panel, weaken a failed
gate, merge atomically across repositories, or claim completion from windows,
labels, a clean merge, or narrative alone.
