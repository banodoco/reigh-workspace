# North Star

Give every tool one runtime-owned lifecycle for derived artifacts: primary image/video/audio generation outputs are durable by default; previews, crops, filmstrips, HTML, exact frames and similar derivatives are temporary by default. Shared-byte references, leases, pins, retention, promotion and deletion are digest-safe and auditable.

Extensions declare output intent through the existing capability/result-manifest contract. No pack-local database, review-specific event family, or path-based authority.
