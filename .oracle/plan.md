## 4. North Star check

*One authority:* unchanged — SQLite sole structured truth, SHA-256 tree sole bytes; T1 hoists publication above the transaction so a committed row never precedes durable bytes. The E5 merge strengthens this: it mutates `asset_registry_json` inside the same writer-serialized UoW with a head-CAS — explicitly **not** a second placement authority, and reusing `timeline.saved` was rejected precisely because it would break event-log reconstructability. *Correctness by primitives:* every named primitive keeps its named test, plus two new ones the evidence forced — sweeper-liveness (wedged executor reclaimed) and save-storm (no silent registry loss under concurrency); the fresh-ULID-key rule for sweeps is itself a receipt-primitive correctness detail. *Invisible failure:* E6's finding was invisible failure incarnate — a crashed executor wedged its task forever with no code path noticing; the sweeper closes it, and T13 gains lease-death crashes. *Growth by declaration:* generations stay event-less data (legal per E4, no manifest grammar change), capabilities stay flat declarative entries with one binding; the single new event kind exists because a current consumer (reconstructability + conflict proof) demands it, not as ceremony. *Honest latency:* polling claim/heartbeat/sweeper over promised budgets; no SSE, no transport-dependent correctness. Anti-patterns explicitly rejected this revision: partial amendment scoping leaving dual crash-window conventions; a parallel quarantine dir beside the existing frozen staging discipline; a third-party multipart dependency for a loopback bridge; a 0600 token-file protocol for a problem the architecture doesn't have; LWW or layered CAS objects in the registry merge; lazy on-claim expiry sweeps that entangle claim's receipt contract. Deferred as not pulling weight: orchestrator transition surfaces, `NON_EXECUTABLE_COMMAND_KINDS` cleanup (tracked N4), paging/thumbnails/GC beyond existing startup GC.
