# B4 — Remaining gaps for a shippable simple local Reigh

**Scope truth:** timeline CAS save/load, discovery, asset serving (Range/ETag), polling, and client undo already work end-to-end against the real bridge. The product-shaped gaps are all in the generation/export/media/ops layers — exactly what the frozen bridge deliberately omits (09 §1/§6; 13 §7.2).

## Top five sequencing

1. **P0-1 + P0-5**: prod local mode + one-command launch (everything else only testable here).
2. **P0-2**: minimal task wire + same-host executor loop + `expire_overdue`; one family vertical slice (wan_2_2_t2i, roadmap Phase 2).
3. **P0-3**: media import/output through the kernel (dedupe, metadata, thumbnails).
4. **P0-4**: local export with progress/cancel; retire worker-banodoco from local.
5. **P1-1/P1-4/P1-6**: secrets UX, bridge-down error UX, backup exposure — the "supportable" layer before ship.

## False alarms / already covered

- **Timeline bridge** (save CAS, 409, discovery, asset Range/ETag, polling): implemented + unit + real-bridge e2e (`AstridBridgeDataProvider.ts`, `real-bridge.spec.ts`; 09 §1).
- **Append-service replacement**: local bridge save *is* the replacement; `append_service.py` stays Supabase-side and is unused locally.
- **Event history/undo**: hash-chained events + `read_events` implemented (04 §4.1); client `useTimelineHistory.ts` covers single-user undo; kernel compaction not needed for MVP.
- **Backup/restore, secrets redaction core, health checks, effects/transitions built-ins**: all implemented — only wiring/UX missing (P1 rows). DB-backed effect/sequence catalogs correctly go dark locally (`userId: null`).
- **Cut scope** (auth/RLS/PATs, credits/Stripe, sharing, training, RunPod, SSE): correctly absent; not gaps.
