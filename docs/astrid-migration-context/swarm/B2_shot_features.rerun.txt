## 2. RPCs and invariants (migrations + 06 §8.C)

- `add_generation_to_shot` — idempotent slot; frame = max+50 or NULL (20260129100000).
- `batch_update_timeline_frames` — atomic set-based multi-row frame update; drag hot path (20260218163000).
- `reorder_normalized` — renormalize to 0/50/100; `delete_and_normalize`, `unposition_and_normalize` (20260130000000).
- `insert_shot_at_position` — shift ≥ position, insert, ensure parent (20260404000000).
- `duplicate_shot` (positioned images only, no videos; 20260113000000) / `duplicate_shot_with_videos` (clone + remap IDs; 20260508160000).
- `create_shot_with_generations` — frames 0,50,100… (20260406) — **absent from generated types.ts**.
- `duplicate_as_new_generation` — new gen + original variant + unique frame walk (20260407010000) — **absent from types.ts**.
- `demote_orphaned_video_variants` — clear stale child-video location, preserve is_primary (20260224000001).
- `ensure_shot_parent_generation` — reuse existing, never replace (20260218143000).
- `update_tool_settings_atomic` — atomic JSON merge into users/projects/shots settings (06 §3.1).
- DB triggers/indexes: exactly-one primary (partial unique + `handle_variant_primary_switch`); original-variant undeletable; `UNIQUE(shot_id, timeline_frame)` **dropped, never restored** — uniqueness now only inside RPCs.

## 3. MVP survival summary

Survives (shot editor core, ≥ TL/GT/AL): shot list/create/rename/delete/reorder, aspect, image add/reorder/position/unposition with normalized-frame invariants, variants + one-primary, generation kickoff/status/outputs, pair settings + enhanced prompts, trim/reposition, travel-between-images end-to-end. The relational shot timeline is already the pack-v2 shape — `generations`, `generation_variants` (one-primary unique), `shot_generation_items` (frame + sort_key) (17) — and the video timeline stays the frozen CAS core (22), so the shot timeline maps 1:1 onto pack-v2 items; "document registry" expresses cross-editor media references, not shot slots. Deferred: shot/variant duplication, demote-orphans, child cascade, external-upload atomicity hardening. Cut (15 Q5): viewed-marking, promote-to-generation (already dead), sharing/referrals/credits/auth/training/agent-sessions. Bridge exposes only reads (R11/R12) + task creation (R1) + CAS save — all shot-editor writes need route/UoW additions (18).

## 4. Uncertainties

- `UNIQUE(shot_id, timeline_frame)` removed — whether pack v2's UNIQUE shot+generation restores frame uniqueness [INFERENCE: yes per 17].
- Two-step external-upload insert is non-atomic client-side; pack v2 `record_completion` UoW assumed as replacement (17).
- Two live RPCs missing from generated types (above) — types drift, not behavior.
- `metadata` JSON schemas (`pair_*`, `enhanced_prompt`, `segmentOverrides`) not specified in pack DDL; must survive as opaque JSON.
- Shot-vs-project settings precedence (`update_tool_settings_atomic` scopes) and 30 s/15 s/3 s polling cadence under the 1–2 s bridge polling (15 Q7) [INFERENCE].
- Whether pack v2 ships in MVP phase or later (22 roadmap phases 2–3).
